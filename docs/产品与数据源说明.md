## 2. 原始影像为什么是"一堆文件"

> 卫星不是相机。它按**光谱通道（波段）**分别采样，每个"波段"就是特定波长区间拍的
> **一张单色照片**。彩色影像是把其中 3~4 张单色照叠出来的（R=红波段、G=绿波段、B=蓝波段）。

### 2.1 Sentinel-2（每景 13 个 tif）

| 文件后缀 | 波段名 | 波长 | 分辨率 | 用途 |
|---|---|---|---|---|
| `.coastal.tif` | B01 coastal aerosol | 443nm | 60m | 海岸带/气溶胶校正 |
| `.blue.tif` | B02 blue | 490nm | **10m** | 真彩 B 通道；水体强穿透 |
| `.green.tif` | B03 green | 560nm | **10m** | 真彩 G 通道 |
| `.red.tif` | B04 red | 665nm | **10m** | 真彩 R 通道 |
| `.rededge1/2/3.tif` | B05/06/07 red edge | 705/740/783nm | 20m | 叶绿素精细监测、作物长势 |
| `.nir.tif` | B08 NIR | 842nm | **10m** | NDVI 主力（NIR−red）/(NIR+red) |
| `.nir08.tif` | B8A narrow NIR | 865nm | 20m | 红边指数 |
| `.nir09.tif` | B09 water vapour | 945nm | 60m | 卷云检测、水汽 |
| `.swir16.tif` | B11 SWIR-1 | 1610nm | 20m | 水分含量、火烧点、干湿 |
| `.swir22.tif` | B12 SWIR-2 | 2190nm | 20m | 矿物/雪/云区分 |
| `.scl.tif` | SCL scene classification | — | 20m | **分类层**：ESA 预分好云/云影/雪/水/裸土等 11 类，去云直接读它 |

### 2.2 Landsat 8/9（每景 8 个 tif）

| 文件后缀 | 波段名 | 波长 | 用途 |
|---|---|---|---|
| `.coastal.tif` | SR_B1 | 443nm | 沿海气溶胶 |
| `.blue/green/red.tif` | SR_B2/3/4 | 480/560/655nm | 真彩三通道 |
| `.nir08.tif` | SR_B5 | 865nm | NDVI |
| `.swir16/swir22.tif` | SR_B6/7 | 1610/2200nm | 短波红外 |
| `.qa_pixel.tif` | 质量位层 | — | **不是照片**：每像元 16bit 整数位标志（云/云影/雪/水），Landsat 去云读它（对应 S2 的 SCL） |

### 2.3 为什么同名波段文件大小/尺寸差几倍

每波段**原生分辨率不同**（10m/20m/60m）。同一个 AOI 窗口：

```
red/green/blue/nir     → 6715×4350（10m，太原示例）
rededge*/swir*/scl     → 3358×2175（20m）
coastal/nir09          → 1120×725 （60m）
```

源是云端 COG（Cloud Optimized GeoTIFF），按 bbox 只拉需要的窗口，不整景下载
（S2 整景单波段 600+MB，13 波段约 8 GB，无必要）。

### 2.4 用途速查

```
blue/green/red          → 真彩色合成（彩色成果）
red + nir               → NDVI
red + rededge*          → 叶绿素/作物胁迫
swir16/22 + nir         → 火点/干湿/矿物
scl / qa_pixel          → 云掩膜（成果里 NaN 的来源）
```

> 「原始影像多文件」不是冗余——每张灰度图承载一个波长区间的内容；
> processed 的 4 波段只是从中挑最常用的 RGBN 堆栈，其余波段都在 raw 里备用。

## 3. 原始 DN → 彩色成果的原理（四步）

1. **DN → 地表反射率（radiometric normalization）** `normalize/reflectance.py`
   卫星下传的 DN 只是量化计数。按卫星官方定标参数线性变换：
   - Landsat L2 SR：`ρ = DN × 2.75e-05 − 0.2`（USGS scale/offset）
   - Sentinel-2 L2A：`ρ = DN ÷ 10000`（BOA 定标）
   换算后"红波段 0.03"= 地表反射 3% 红光，跨传感器数值可比。

2. **多传感器一致性（harmonize）** `normalize/harmonize.py`
   S2/Landsat 波段宽度与光谱响应略异，用 HLS 式经验系数把 S2 调到 Landsat 基线，
   保证不同卫星的"红"是同一个红——镶嵌、时序不掉色的前提。

3. **波段组合（band composition）** `pipeline/steps.py::_step_stack`
   - 真彩色：R←red、G←green、B←blue（植被反射红光少、绿光多→绿；云/雪/水泥三波段都高→白）
   - 同时堆 **NIR** 第四波段：植被叶片近红外强反射，NDVI/假彩色反演都不用重下载
   - 云例外：`process/clouds.py` 先解码 qa_pixel/SCL 位标志（含邻域缓冲），
     云/云影像元置 NaN——否则白云会当"假雪"混进真彩色。

4. **显示拉伸（stretch）** `process/color.py`
   反射率数值域通常 0~0.4，直接转 8 位灰暗。导出预览/PNG 时做 2% 线性拉伸
   （累积直方图 2%~98% 分位映射到 0~255）。**COG 里存的仍是未拉伸 float 反射率**，定量分析可用。

## 4. 已知数据源坑（修复记录）

| 问题 | 现象 | 根因与修复 |
|---|---|---|
| S2 PB≥04 双扣偏移 | 成果整体发暗、颜色怪（城市暗部归零） | earth-search 资产 `raster:bands` 标注 `offset=-0.1`，但像素**已剔除偏移**（`earthsearch:boa_offset_applied=True`）→ `scaling_from_stac` 现检测该标志强制 offset=0（`normalize/reflectance.py`，回归测试 `test_scaling_from_stac_ignores_raster_offset_when_boa_offset_applied`） |
| QA 角色抢占 | 掩膜 97% 全暗 | `qa_aerosol`(data-mask 角色) 抢占 `qa_pixel`(cloud 角色) → `bands.py::QA_ROLES` 顺序改为 cloud 优先 |
| GDAL /vsicurl 在 Windows 不可用 | schannel 证书吊销错误 | 改自研 `CogReader`（HTTP Range 按 660×512 瓦片读，`ingest/cogreader.py`） |
| 跨境网络慢/断连 | 单波段 25MB 拖 30 分钟 | `RangeFile` 块 256KB→8MB + 5 次重试；raw 下载 6 线程并行（`ingest/rangefile.py`） |
| PC 资产需签名 | Azure Storage 403 | `ingest/signing.py` 自动换 SAS 签名（缓存 ~1h） |
| 多源重复覆盖 | 同景 usgs-landsat 覆盖 PC 命中 | `run_scene_ids` 改 `setdefault` 先到先得 |

## 5. 成果产品规格

| 项 | raw 原始 | processed 成果 |
|---|---|---|
| 位置 | `data/raw/<源>/<景>/` | `data/derived/cog/<景>.tif` + `data/catalog/<城>/<景>.json` |
| 值域 | uint16/uint8 DN（定标前） | float32 反射率 0~1（NaN=云/无数据） |
| 波段 | 全波段（S2 13 件 / LS 8 件） | 4 波段 red/green/blue/nir |
| 处理 | 无（AOI 裁剪 + deflate） | 归一化→均衡→COG 重编码→去云→STAC |
| 用途 | 复算/自定义定标/其他指数 | 直接出图/指数/镶嵌 |
| 典型大小 | S2 ~450MB、LS ~60MB（AOI 窗口） | S2 145~378MB、LS 39~85MB |

STAC item 回填字段（`rspi:*`）：`source_provider/source_collection/source_scene_id/product_level/radiometry/tier/scene_cloud_cover/aoi_cloud_cover/valid_fraction/aoi_bbox`。

## 6. 脚本操作

```powershell
# 下载一个城市（选景+raw+processed 一条龙；选景由 quality.rank_scenes 自动排：
#   Landsat 一年窗口内 Tier1 优先 + AOI 实测云量 + 覆盖度；S2 近月窗口）
python scripts/download_taiyuan.py raw         # 只下原始（断点续传，8MB块×6线程）
python scripts/download_taiyuan.py processed   # 只生成成果（自动走"本地raw快速通道"零网络）
python scripts/download_taiyuan.py all         # 两步连跑

# 换城市：改脚本头部 TARGETS（provider, collection, scene_id）+ AOI bbox + AOI_NAME

# 注册 STAC 索引（下载后）
python -m rspipe.cli index --catalog data/catalog/taiyuan --collection taiyuan

# 查询 / 镶嵌 / 预览
python -m rspipe.cli search --bbox 112.15,37.55,112.90,38.20 --cloud-aoi 5
python -m rspipe.cli run --aoi configs/aoi_taiyuan.geojson --cloud-aoi 5   # 定时增量
python -m rspipe.cli status        # 索引/水位线

# 定期更新（调度）
python -m rspipe.scheduler         # 读 pipeline.yaml 的 schedule 段
```

测试：`python -m pytest tests -q`（87 项）；风格：`python -m ruff check src tests scripts`。

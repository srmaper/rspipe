# 开发问题与经验

按"现象 → 根因 → 修复 → 规避"记录本项目实际踩过的坑。新问题继续往下追加。

---

## 一、数据源与定标

### 1.1 S2 处理基线 PB≥04 偏移被扣两次（整图发暗）

- **现象**：S2 成果整体暗黄，城市暗部全黑；红波段均值 0.0925 → 0.0204。
- **根因**：earth-search 的资产 `raster:bands` 仍带 ESA 原生标注 `offset: -0.1`，
  但他们的 COG 像素**已剔除该偏移**（`earthsearch:boa_offset_applied = true`）。
  定标优先采信 `raster:bands` → 又减了一次 0.1。
- **修复**：`normalize/reflectance.py::scaling_from_stac` 检测该标志时强制 `offset=0`；
  回归测试 `test_scaling_from_stac_ignores_raster_offset_when_boa_offset_applied`。
- **规避**：**元数据自相矛盾时以像素实测为准**。新增数据源先做一次"DN 直方图 vs 官方定标"
  的抽样对比，别信标注。

### 1.2 QA 波段角色抢占（掩膜 97% 全灭）

- **现象**：Landsat 掩膜后仅 2.6% 有效像元，而直接解码 QA 只有 24.67% 云。
- **根因**：`qa_aerosol` 的 roles 含 `data-mask`，在 `QA_ROLES` 里排在 `cloud` 之前，
  被当成云标志解码（气溶胶位被解释成云）。
- **修复**：`bands.py::QA_ROLES` 顺序改为 `cloud → cloud-shadow → snow-ice → water-mask →
  data-mask`；回归测试 `test_qa_asset_prefers_cloud_role_over_data_mask`。
- **规避**：多 QA 资产的产品（Landsat C2）**永远按角色而非文件名挑 QA**，并断言
  "掩膜有效比例 ≈ 独立解码结果"。

### 1.3 STAC 云量 ≠ AOI 云量（选到最差的景）

- **现象**：深圳选景 STAC 显示云 8%，实际 AOI 内 97% 是云。
- **根因**：`eo:cloud_cover` 是整景（185×180 km）统计，AOI 只占一角。
- **修复**：新增 `quality.py`，拉 QA/SCL 的 AOI 窗口实测云量；`rank_scenes` 按
  `Tier 惩罚 + AOI云量×10 − 覆盖度` 排序。
- **规避**：**任何"按云量筛选"都必须落到 AOI 窗口**；整景云量只能做粗筛。

### 1.4 多数据源同名景覆盖

- **现象**：同一景在 usgs-landsat（需登录）命中，覆盖了 planetary-computer 的可用副本，下载 403。
- **修复**：`Pipeline.run_scene_ids` 用 `setdefault` 先到先得（公共源优先）。

## 二、网络与传输

### 2.1 Windows GDAL `/vsicurl/` 不可用

- **现象**：远程 COG 打不开，`CERT_TRUST_REVOCATION_STATUS_UNKNOWN`；任何 GDAL 配置都绕不过。
- **修复**：自研 `CogReader`（按 TIFF 结构用 HTTP Range 拉命中瓦片）+ `RangeFile` 可 seek 远程文件。
- **规避**：Windows 上**不要依赖 GDAL 的远程驱动**，自己实现 Range 读取。

### 2.2 跨境网络慢/断连（单波段 25 MB 要 30 分钟）

- **根因**：256 KB 块 → 每块一次请求，跨境 RTT 高；无重试。
- **修复**：块大小 256 KB → 8 MB；`_fetch_block` 5 次指数退避重试；raw 下载 6 线程并行。
  实测 13 波段 38 秒（此前 2 小时+）。
- **规避**：跨境对象存储**大块 + 并行 + 重试**是标配；先量 RTT 再定块大小。

### 2.3 进度条长时间 0%（看起来卡死）

- **根因**：进度只在"整块/整波段收完"回调；流式读取一个 8 MB 块要几分钟。
- **修复**：`RangeFile` 改 `httpx.stream()`，**每 64 KB** 触发 `progress_hook`，任务条按字节推进。
- **规避**：**进度回调粒度必须小于单次 I/O 时长**，否则等于没有。

### 2.4 `localhost` 每次请求慢 2 秒

- **根因**：Windows 先解析 IPv6 `::1`，uvicorn 只绑 IPv4 → 超时后回落。
- **修复**：统一用 `http://127.0.0.1:8000`。
- **规避**：Windows 本地服务**用 IP 不用 hostname**。

## 三、影像渲染

### 3.1 瓦片出现横条纹/渐变伪影

- **根因**：瓦片只有一部分落在影像内时，读窗被 clamp 成 1~3 像素，再拉伸到 256 → 细线放大成条纹。
- **修复**：统一 `plan_tile_window()`：瓦片 ∩ 影像 → 交集在瓦片中的**相对位置**决定 256 画布子矩形，
  交集在栅格中的**像素窗口**决定读哪块；无值区透明。
- **规避**：**任何"窗口读取 + 缩放"都要处理部分覆盖**，不能简单 clamp。

### 3.2 黑块盖住底图

- **根因**：无值区填了深灰 40，且边缘瓦片也返回整块灰图。
- **修复**：输出 RGBA（无值 alpha=0）；有效像元 <1% 直接 204。
- **规避**：瓦片服务**无数据必须透明或 404/204**，别用实色填充。

### 3.3 预览缩放不跟 AOI

- **根因**：`fitBounds` 写死 `maxZoom: 11`；且用的是景范围而非裁剪范围。
- **修复**：`maxZoom: 18`；缩放优先级 `raw_bounds（裁剪实际范围）> AOI > 景范围`。
- **规避**：**不要给 fitBounds 设过低上限**；缩放范围应与"用户实际拿到的数据范围"一致。

### 3.4 整景预览的"2 GB"误解

- **教训**：曾尝试"整景下载后预览"，S2 全幅 4 波段 float32 ≈ 2 GB，跨境根本拉不动。
- **正确做法**：读 COG 的**金字塔层**（`CogReader.levels` + `pick_level`），单瓦片几十 KB。
  后来进一步收紧：预览只用**本地已下载数据**，不回源云端。

## 四、前端

### 4.1 组件整卡消失 / 页面空白

- **根因**（两次）：
  1. `sCfg` 未声明就用于模板 → setup 抛错，整树不渲染；
  2. `SearchCard` 用了 `computed` 但漏 `import { computed } from 'vue'`。
- **规避**：新增组件后**必须真实打开页面看**；构建成功 ≠ 运行成功。
  批量改 SFC 时对每个文件做 "uses vs imports" 检查。

### 4.2 `setDrawMode is not defined` + Map 容器报错

- **根因**：函数写在 `onMounted` 闭包里，`defineExpose` 在 setup 作用域引用不到。
- **规避**：**暴露给父组件的方法必须定义在 setup 顶层作用域**。

### 4.3 `[object Object] raw` 按钮文案

- **根因**：`computed(...)` 返回 ComputedRef，在 computed 外做字符串拼接。
- **规避**：模板插值用 ref 会自动解包，**但 JS 表达式里必须 `.value` 或把拼接放进 computed**。

### 4.4 检索"点了没反应"

- **根因**：providers 被前端拼成 `{provider, collection}` 对象，schema 要 `[[p, c]]` → 422；
  且 `onSearch` 不看 `r.ok`，错误被静默吞掉。
- **修复**：前端改数组；后端加 `field_validator` 双形态兼容；所有 fetch 检查 `ok` 并 toast/日志。
- **规避**：**任何 fetch 都要处理非 2xx**；前后端约定结构写进 schema 并在测试里固化。

### 4.5 右栏列表没有滚动条

- **根因**：flex 子项缺 `min-height: 0`，拒绝收缩 → 内容溢出而不是内滚。
- **规避**：flex 列布局里做滚动容器，**父链上每一级都要 `min-height: 0`**。

### 4.6 首次加载不显示底图

- **根因**：`map.on('load')` 时 `isStyleLoaded()` 因瓦片仍在流会回 false，`setBasemap` 整段空转。
- **规避**：**以 `load` 事件为准，不要用 `isStyleLoaded()` 当门槛**（参考项目注释里同样记录过）。

### 4.7 注记被矢量层压盖

- **根因**：注入 carto 矢量层用 `addLayer` 追加到顶部，把注记层压住。
- **修复**：注入后 `moveLayer('label')` 提顶，再 `restackBusinessLayers` 把 AOI/足迹/预览归顶。
- **规避**：动态加层后**显式管理层序**，别依赖添加顺序。

## 五、后端与服务

### 5.1 并发写同一景 staging 目录（Permission denied）

- **现象**：`CPLE_AppDefinedError: Deleting ...stack.tif failed: Permission denied` 直接弹到界面。
- **根因**：同一景的多个任务并发跑 `SceneProcessor`，后者 `open('w')` 先删前者句柄。
- **修复**：`JobCenter.submit` 同景同类型去重 + 每景 `threading.Lock` 串行化；
  底层异常映射成人话（"文件被占用，稍后重试"）。
- **规避**：**任务队列必须按资源（景/目录）串行化**；用户可见错误要翻译，不能直出 GDAL 原文。

### 5.2 重启后任务列表清空

- **根因**：`JobCenter.jobs` 只在内存。
- **修复**：落盘 `data/index/web_jobs.sqlite`（提交/每 2% 进度/终态都写），启动回放 200 条，
  被中断的 running 标为 error 并提示可重下。
- **规避**：**任何用户可见状态都要持久化**，内存只做缓存。

### 5.3 导出 404 / 只打了一半文件

- **根因**：导出强制要求 processed COG；且缓存不失效（后补 COG 不进包）。
- **修复**：改为"有什么打什么"（COG/raw/STAC 三者全无才 404）+ 源文件比 zip 新则重打包。
- **规避**：导出类接口**按产物存在性降级**，缓存要带失效判断。

### 5.4 服务莫名停止

- **根因**：`Start-Process cmd` 起的隐藏控制台被关闭/信号带走。
- **修复**：`scripts/web_server.cmd`（先杀 8000 占用 → 启动 → 出错保持窗口）。
- **规避**：长驻服务用脚本统一入口，别在临时 shell 里手动起。

### 5.5 服务"卡住"其实在跑

- **教训**：用 `py-spy dump` 抓栈才看清线程都在 `_fetch_block` 流式读网络，不是死锁。
- **规避**：**先抓栈再改代码**，别凭"看起来不动"猜。

## 六、工程与环境（Windows）

| 坑 | 规避 |
|---|---|
| PowerShell 不支持 heredoc | 多行补丁写 `_tmp_*.py` → 执行 → 删除 |
| `npm`/`rg` 被执行策略或别名拦截 | 用 `npm.cmd`；搜索用工具而非 shell 别名 |
| PowerShell 里拼含引号的 Python 字符串极易写坏 | 用 `edit`/`write` 工具，不拼长字符串 |
| 控制台中文乱码 | 只是 GBK 显示问题，文件本身 UTF-8；断言时比对字节 |
| 工作目录混用导致路径找不到 | 所有命令显式 `workdir`，脚本内部用绝对路径 |

## 七、方法论沉淀

1. **先量后改**：网络慢先测吞吐/RTT，服务卡先 `py-spy dump`，坐标错先算数值相关性（本次用互相关 0.973 证明对齐）。
2. **数值验证优于目测**：瓦片质量用 `rowvar/colvar`、互相关、覆盖矩形与理论矩形比对，而不是截图看。
3. **元数据可能自相矛盾**：以像素实测为准，写回归测试固化。
4. **用户可见的每一步都要有状态**：进度按字节、错误翻译成人话、任务持久化。
5. **构建成功 ≠ 功能可用**：每次改前端都要真实打开页面/走接口验证。
6. **清理数据只按产物目录/前缀**，不做大范围删除；用户文件一律不动。

## 八、二次迭代（首页 / 分析页 / 双屏）

### 8.1 影像与底图错位（整体拉伸）

- **现象**：预览影像压在错误位置，形状被拉伸。
- **根因**：MapLibre raster source 的 `bounds` 给成了**整景范围**，而瓦片内容只有 AOI 裁剪范围 →
  客户端把瓦片网格硬映射到整景。
- **修复**：`bounds` 用**数据实际范围**：`raw_bounds → cog_bounds → AOI → 景范围`。
- **规避**：raster source 的 bounds 必须等于瓦片内容覆盖的地理范围。

### 8.2 低层级预览错位（10~20%）

- **现象**：z5–z8 时影像明显偏小/偏位，高缩放正常。
- **根因**：`plan_tile_window` 先把瓦片角点转到 UTM，再按 UTM 比例算像素位置；
  墨卡托→UTM 的尺度随纬度变化，z6 瓦片跨 5.6° 时误差被放大到 20%。
- **修复**：比例在**墨卡托(3857)空间**计算（瓦片像素与 3857 米严格线性），
  只在最后把交集转回栅格 CRS 取像素窗口。
- **验证**：真实数据内容矩形 vs 理论矩形，误差从 6px 降到 ≤1px。
- **规避**：跨投影的“比例映射”必须在**线性空间**做，不要在目标投影里近似。

### 8.3 瓦片拼接花斑

- **现象**：相邻瓦片颜色差异大，像拼贴。
- **根因**：每张瓦片各自做 2%/98% 拉伸，直方图不同 → 同地物不同色。
- **修复**：按景缓存拉伸区间（整景 128×128 采样取分位），所有瓦片共用。
- **验证**：合成渐变影像，相邻瓦片接缝色差 0.0。

### 8.4 范围线被影像压盖

- **现象**：红色影像范围框时隐时现，切通道后消失。
- **根因**：`restackBusinessLayers` 的图层名单里**漏了 `pext-line`**，
  每次归层都把 preview 提到它上面；另外切“范围”显示时没有归层。
- **修复**：名单补 `pext-line`，并在显示切换后与地图 `idle` 时各归层一次。
- **规避**：凡是动态加层，都要有**集中的归层函数**并把新层登记进去。

### 8.5 前端 prop 名不一致导致图层不渲染

- **现象**：分析页点计算后统计有结果，但地图不出图。
- **根因**：`MapCanvas` 的 prop 叫 `previewScene`，分析页传的是 `:preview` → 监听器收不到。
- **规避**：组件 props 与使用处对齐后，用**无头浏览器验证瓦片请求数**（不是只看接口 200）。

### 8.6 分析：两期统计里 `b` 变成 None

- **根因**：补丁脚本里残留一行 `b = ... if False else None`，把函数参数 `b` 覆盖了。
- **规避**：改完跑一次真实请求核对返回字段，不只跑单元测试。

### 8.7 分析：变化面积为 0

- **根因**：用 4326 的 `transform[0]*transform[4]`（单位：度）当像元面积。
- **修复**：按纬度加权换算米制像元面积（`dx≈111320·cos(lat)`，`dy≈110540`）。
- **规避**：**面积/距离统计永远在米制空间算**，经纬度栅格要换算。

### 8.8 补丁脚本“判断顺序”导致方法缺失（500）

- **现象**：点下载无反应，`POST /api/jobs` 500，日志 `AttributeError: _db_delete`。
- **根因**：补丁先插入**调用**再判断 `if "方法名" not in 源码`，判断被调用行命中 → 方法定义被跳过。
- **规避**：补丁判断用 `def 方法名(` 精确匹配；改完必须真实调用一次接口。

### 8.9 日志文件被占用删不掉

- **根因**：`web_server.cmd` 是 `:run` 循环（崩溃自动拉起），只杀 python 会立刻重启并重新占用日志。
- **修复**：先杀 `cmd.exe`（命令行含 `web_server.cmd`）再杀 python，最后删日志。
- **规避**：常驻服务的日志轮转要**先停 supervisor**，或改用按日期切分文件。

### 8.10 地图浮层各页面各写一份

- **问题**：底图切换、经纬度条写在下载页里，分析页复用 `MapCanvas` 时就没有。
- **修复**：把底图切换与坐标条**下沉进 `MapCanvas` 组件**，页面只保留业务浮层。
- **规避**：地图相关的通用控件放在地图组件内，避免复制粘贴产生不一致。

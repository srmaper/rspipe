# 遥感影像应用能力介绍

> 数据基础：Sentinel-2（13 波段，10/20/60 m，双星 5 天重访）、Landsat 8/9（地表反射率 + 热红外，16 天重访）
> 处理能力：辐射定标、去云、匀色、镶嵌、STAC 元数据、AOI 裁剪、4326 预览栅格、瓦片服务
> 适用尺度：地块级 ~ 区域级（10 m 分辨率），单栋建筑/车辆等小目标不在范围内

---

## 一、城市与规划

### 1.1 建成区扩张与城市蔓延
- **做法**：NDBI =（SWIR1 − NIR）/（SWIR1 + NIR），配多时相统计
- **产出**：各年份建成区范围、新增建成区面积、扩张方向
- **数据**：S2/Landsat 的 `swir16`、`nir`；建议每年 1~2 期
- **平台**：检索（AOI + 时间窗）→ 下载 → 假彩/NDVI 预览 → 指数计算

### 1.2 城市绿地率与公园覆盖
- **做法**：NDVI 阈值分割（如 >0.4 判为植被）+ 面积统计
- **产出**：绿地面积、绿地率、绿地分布图、人均绿地（配人口数据）
- **数据**：`red`、`nir`；单期即可，季节需一致（建议夏季）

### 1.3 城市热岛
- **做法**：Landsat 热红外（`lwir11`）反演地表温度 LST，与 NDVI/不透水面叠加分析
- **产出**：地表温度图、热岛强度、热岛与绿地/建成区关系
- **注意**：热红外原生 100 m，需降尺度才能与 10 m 影像精确叠合

### 1.4 工地/违建动态监测
- **做法**：多期真彩色 + 变化检测（裸土指数、纹理突变）
- **产出**：新增扰动图斑、施工进度变化
- **数据**：`blue/green/red` 时序（月度）

## 二、农业

### 2.1 作物种植结构识别
- **做法**：多时相 NDVI/NDRE 曲线 + 物候特征分类
- **产出**：作物类型分布（水稻/玉米/蔬菜等）、种植面积
- **数据**：生长季 6~10 期；S2 红边波段（`rededge1~3`）区分作物类型更准

### 2.2 长势监测与估产
- **做法**：NDVI、EVI、红边叶绿素指数；与历史同期对比
- **产出**：长势分级图（好/中/差）、异常地块清单
- **注意**：估产需地面样方或统计年鉴标定

### 2.3 旱情与土壤墒情
- **做法**：NDWI、SWIR 水分指数、植被供水指数
- **产出**：干旱等级分布、受影响面积

### 2.4 灾情定损（洪涝/冰雹/倒伏）
- **做法**：灾前灾后 NDVI 差值（ΔNDVI）+ 受灾阈值
- **产出**：受灾范围、受灾面积、损失评估底图
- **应用**：农业保险定损、政府灾情上报

## 三、林业与生态

### 3.1 森林覆盖与变化
- **做法**：NDVI + SWIR 组合，多时相变化检测
- **产出**：森林范围、年度减少/增加面积、疑似砍伐图斑

### 3.2 病虫害与胁迫早期识别
- **做法**：红边指数（NDRE、CIre）；比 NDVI 提前 1~2 周发现异常
- **产出**：异常林班/地块清单（需人工核查确认）

### 3.3 生态修复与保护地监测
- **做法**：裸地指数 + 时序植被恢复趋势
- **产出**：修复区植被覆盖变化曲线、人类活动图斑

---

## 四、水环境

### 4.1 水体提取与岸线变化
- **做法**：NDWI =（Green − NIR）/（Green + NIR）> 0 判水体
- **产出**：水体范围、面积、岸线迁移、填占水域图斑

### 4.2 水质指示（半定量）
- **做法**：浊度（红波段反射率）、叶绿素 a（红边/近红外比值）、黑臭水体多波段组合
- **产出**：水质异常区分布（相对等级，非浓度绝对值）
- **注意**：定量浓度需现场采样标定

### 4.3 蓝藻水华监测
- **做法**：NDVI 异常高值 + 时相追踪
- **产出**：水华范围、面积、扩散趋势

## 五、灾害应急

| 灾种 | 方法 | 产出 |
|---|---|---|
| 洪涝 | 灾前灾后 NDWI/水体范围对比 | 淹没范围、受淹面积、受影响居民点 |
| 火烧迹地 | NBR =（NIR − SWIR2）/（NIR + SWIR2）、dNBR 分级 | 过火范围、 severity 分级 |
| 滑坡/崩塌 | 真彩变化 + 纹理异常 | 疑似灾害点位置 |
| 台风/地震损毁 | 建成区掩膜 + 变化检测 | 受损建筑区分布（街区级） |

> 光学受云限制，灾害应急建议配合 SAR 数据；我们的云掩膜可先剔除无效区，避免误判。

## 六、国土与执法监察

- **违法占地/耕地非农化**：时序 NDVI + 地类变化，输出疑似图斑与坐标
- **矿山开采与修复**：裸地指数、时序扰动范围
- **围填海/岸线侵占**：水体/陆地边界时序变化
- **土地执法核查底图**：真彩 + 范围矢量，供外业核对

---

## 七、能源与工程

- **光伏/风电选址初筛**：土地利用 + 坡度 + 距建成区距离（需 DEM/矢量辅助）
- **输电线路/管道选线**：地表覆盖、地质灾害易发区叠加
- **施工进度监测**：月度真彩，输出扰动范围与进度对比

- 遥感指数实验（NDVI/NDWI/NDBI/NBR 计算与验证）
- 城市扩张、植被变化等长时序研究

## 九、平台对应的操作路径

```
① 圈选 AOI（或地名搜索）
② 检索：时间窗 + 整景云量上限（建议 ≤10%）
      → 按 Tier1 > AOI 实测云量 > 覆盖度 排序
③ 选波段下载（常用 RGBN + SCL/QA，够做真彩/假彩/NDVI）
      → 自动生成 4326 预览栅格 + AOI 记录
④ 预览：真彩色 / 假彩 NIR / NDVI，叠加红框标出影像范围
⑤ 导出 zip：原始波段 + 合成反射率 + 4326 预览栅格 + AOI + 快视图 + README
⑥ 在 QGIS/ArcGIS 或自研模型中做指数计算、分类、变化检测
```

## 十、能力边界（务必提前说明）

| 限制 | 说明 | 应对 |
|---|---|---|
| 分辨率 10 m | 适合地块/区域级；单栋建筑、车辆不可辨 | 亚米级影像（GF-2、航拍）|
| 光学受云影响 | 华南雨季有效观测少 | 多时相合成 + 云掩膜（已内置）|
| 重访 5/16 天 | 突发灾害可能赶不上 | 配合 SAR、无人机 |
| 定量精度 | NDVI 等为相对指标 | 产量/水质/碳汇需地面标定 |
| 热红外 100 m | 城市热岛需降尺度 | 与高分影像融合 |

---

## 十一、可直接交付的成果清单

1. **真彩/假彩/NDVI 影像图**（带坐标、可叠加 GIS）
2. **AOI 范围内裁剪数据集**（原始 DN + 反射率合成 + 4326 预览）
3. **变化检测图斑**（违法占地、砍伐、水体变化等）
4. **统计报表**（面积、比例、时序曲线）
5. **STAC 元数据**（可对接第三方平台、可复现）

## 1. 现状（v1.1.0 起）

分析页共 **15 个指数**（后端 `src/rspipe/web/analysis.py` 的 `INDICES` / `COLORMAPS` / `INDEX_META`）：

| 类别 | 指数 | 公式 | 依赖波段 |
|---|---|---|---|
| 植被 | NDVI | (NIR−R)/(NIR+R) | red, nir |
| 植被 | EVI ✅新增 | 2.5(NIR−R)/(NIR+6R−7.5B+1) | blue, red, nir |
| 植被 | SAVI ✅新增 | (NIR−R)(1+L)/(NIR+R+L)，L=0.5 | red, nir |
| 植被 | NDRE | (NIR−RE1)/(NIR+RE1) | nir, rededge1 |
| 建筑 | NDBI | (SWIR1−NIR)/(SWIR1+NIR) | swir16, nir |
| 裸土 | BSI | ((SWIR1+R)−(NIR+B))/(…) | swir16, red, nir, blue |
| 燃烧 | NBR | (NIR−SWIR2)/(NIR+SWIR2) | nir, swir22 |
| 燃烧 | NBR2 ✅新增 | (SWIR1−SWIR2)/(SWIR1+SWIR2) | swir16, swir22 |
| 水分 | NDMI ✅新增 | (NIR−SWIR1)/(NIR+SWIR1) | nir, swir16 |
| 水体 | NDWI | (G−NIR)/(G+NIR) | green, nir |
| 水体 | MNDWI ✅新增 | (G−SWIR1)/(G+SWIR1) | green, swir16 |
| 水体 | AWEI ✅新增 | 4(G−SWIR1)−(0.25NIR+2.75SWIR2) | green, nir, swir16, swir22 |
| 水质 | FAI ✅新增 | NIR−基线(Red→SWIR1)，仅水体 | green, red, nir, swir16 |
| 积雪 | NDSI ✅新增 | (G−SWIR1)/(G+SWIR1) | green, swir16 |
| 盐分 | SI ✅新增 | √(Red×SWIR1) | red, swir16 |

要点：

- 阈值、滑块区间、伪彩区间、图例文字都在 `INDEX_META`，新增指数只需加三条记录
  （`INDICES` / `COLORMAPS` / `INDEX_META`），前端零改动。
- 色带由后端 `/api/analysis/meta` 下发（`colors`），前端图例直接读取，避免两边维护两套颜色。
- **FAI 用 MNDWI>0 限定到水体**：陆地 NIR 高，不限定会把整片陆地判成藻类。
- 面积统计、矢量面、快视图、导出 zip、历史记录全部自动复用现有链路。

## 3. 与外部总结的差异（勘误）

对照某 AI 总结（《哨兵与Landsat影像数据分析》）核对后确认：

1. **S2 云掩膜不能用 QA60**：L2A 从处理基线 04.00 起 `QA60` 全为 0（已弃用），必须用 **SCL**；
   本平台 `process/clouds.py::decode_scl` 是正确做法。
2. **S2 反射率不是简单 ÷10000**：2022-01 之后的新基线要 `(DN−1000)/10000`；本平台按
   `boa_offset_applied` 判断，已处理。
3. **LST 不必自己算亮温**：Landsat C2 L2 直接提供 `ST_B10`（地表温度），比单窗算法简单且为官方口径。
4. **FAI 的基线波段用 B8 而非 B8A**：B8A(865nm) 与 B4(665nm) 间距过大，插值误差大。
5. **AWEI 依赖 SWIR（20m）**：只下 RGBN 算不出来，界面需提示补下 `swir16`/`swir22`。

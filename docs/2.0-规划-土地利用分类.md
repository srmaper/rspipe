# 2.0 规划：土地利用分类（LULC）

> 记录于 2026-11-01。状态：**规划中，未开工**。目标版本 2.0。
> 本文是可执行的开发底稿：结论、数据源实测、接口草案、任务拆分与风险都在这里。

## 1. 结论

**能算，但要分清两条路：**

1. **直接用现成产品**（不自己算）—— 10m 全球产品可按 AOI 现取，适合做参考底图、目视校核、面积对比。
2. **用自己的数据算** —— 现有 S2 L2A 13 波段（含 3 红边 + 2 SWIR + SCL）足够分 6 大类；
   阈值规则法能出图（精度约 70–80%），要 85%+ 必须上「样本 + 随机森林 + 多时相」。

2.0 建议先做「规则分类 + 参考产品叠加」，把「样本 + RF」放到 2.x。

要点：

- **WorldCover 与 IO LULC 都能从 AWS 公开桶直接 Range 读取**（不需要 SAS），比走 PC 签名更简单；
  PC 签名路径可复用现有 `src/rspipe/ingest/signing.py`。
- 两者都是 COG，可按 AOI 只读窗口，符合本项目「不下载整景」的原则。
- WorldCover 全球独立验证总体精度 **74.4%**；CLCD 中国区域约 **80%（一级类）/ 91%（二级类）**。

### 类别对照

  80 永久水体、90 草本湿地、95 红树林、100 苔藓地衣。
- IO LULC（9）：0 无数据、1 水体、2 树木、4 洪泛植被、5 耕地、7 建成区、8 裸地、9 冰雪、

## 3. 用自己的数据算：可行性验证

2026-11-01 用本地已下载的 `S2B_50TKK_20261006`（13 波段 + SCL，20.2 km²）跑了一版规则分类：

```
水体 0.0% · 林地 5.6% · 耕地 44.4% · 草地 2.7% · 建设用地 47.0% · 未利用地 0.3%
```

- 结构合理：田块成片、城区连片、河谷有林带。
- **建设用地明显高估**：休耕地 / 收割后的裸田被 NDBI 判成建成区 —— 阈值法的典型问题。

规则（原型）：

```
mask  = SCL ∉ {0,1,3,8,9,10,11}  且 全部波段 > 0
水体  = MNDWI > 0.05
建设  = ¬水体 且 NDBI > 0.02 且 NDVI < 0.35
林地  = ¬水体 ¬建设 且 NDVI ≥ 0.62
耕地  = ¬水体 ¬建设 且 0.35 ≤ NDVI < 0.62
草地  = ¬水体 ¬建设 且 0.18 ≤ NDVI < 0.35
未利用 = ¬水体 ¬建设 且 NDVI < 0.18
```

文献量级（供定预期）：

- 仅光谱波段 + 随机森林：Kappa ≈ 0.85（南方丘陵，2026《北京测绘》多源特征对比）。
- 加光谱指数：提升有限，水田/旱地仍难分。
- 再加 DEM + SAR：Kappa 0.90–0.92。
- JAXA HRLULC（10 m）：S2 时序 + S1 + DEM + OSM，CNN。

## 4. 现有能力与缺口

已有（可直接复用）：

- 波段下载与统一网格重投影（`_read_grid`）、SCL/QA 云掩膜（`src/rspipe/process/clouds.py`：
  `decode_scl` / `decode_qa_pixel` / `build_mask` / `apply_mask` / `dilate_mask`）。
- 指数计算与统计（`src/rspipe/web/analysis.py`）、矢量面（`vectorize_index`）、
  瓦片渲染（`render_index_tile` / `render_raster_tile`）、zip 导出（`export_bundle`）、
  分析历史（`record_run` / `list_history`）、AOI 与原始影像随结果保存（`_copy_sources`）。
- 前端：分析页图层栏（原始影像 / 结果影像 / 双屏比对 / 阈值矢量 / AOI / 关闭）、图例、历史卡片。

缺口：

- 分类模块（规则 / RF）与分类栅格渲染（离散色板 + 图例 + 面积统计）。
- 训练样本的采集与存储（地图点选 / 框选 / 导入 GeoJSON）。
- 多时相合成（同一 AOI 多期 S2 中值合成，解决耕地/草地、水田/旱地混淆）。
- 参考产品接入（WorldCover / IO LULC 按 AOI 拉窗口、叠加、面积对比）。
- DEM / SAR（可选，精度提升用）。
- `scikit-learn` 依赖（打包体积约 +30 MB，需评估是否走可选依赖）。

## 5. 方案拆分

### A. 规则决策树 6 类（约 1 天，2.0 M1）

- 后端 `src/rspipe/web/lulc.py`：
  - `classify_rules(data_root, provider, scene_id, collection, *, mask_clouds=True, thresholds=None)`
  - 输出 `data/lulc/<key>/class.tif`（uint8，EPSG:4326）、`stats.json`（各类面积/占比）、
    `class_vector.geojson`（按类合并面）、`legend.json`。
  - 复用 `_read_grid` 读波段，复用 `process/clouds.py` 做云掩膜。
- 接口：
  - `POST /api/lulc/run` → `{key, tiles, stats, legend, source_tiles}`
  - `GET /api/lulc/tiles/{key}/{z}/{x}/{y}.png`（离散色板，最近邻）
  - `GET /api/lulc/history`、`DELETE /api/lulc/{key}`、`GET /api/lulc/export/{key}`
- 前端：分析页新增「分类」模式（指数下拉换成「分类体系 + 阈值面板」），图例用色块 + 面积；
  图层栏沿用现有按钮，另加「分类矢量」开关。
- 精度预期：70–80%（单景、无样本）。导出 zip 含 `class.tif` + `stats.json` + `legend.json` + 矢量。

### B. 参考产品叠加（约半天，2.0 M2）

- 后端 `src/rspipe/web/lulc_ref.py`：
  - WorldCover：`https://esa-worldcover.s3.eu-central-1.amazonaws.com/v200/2021/map/ESA_WorldCover_10m_2021_v200_<tile>_Map.tif`
    （按 3°×3° 分幅命名，需由 AOI 求分幅编号）。
  - IO LULC：`https://io-10m-annual-lulc.s3.us-west-2.amazonaws.com/<supercell>_<year>.tif`
    （supercell 如 `49S`，由 UTM 带 + 纬度带推出）。
  - 只读 AOI 窗口 → 重投影到与分类栅格同网格 → 面积统计 + 混淆矩阵（以参考产品为"标签"）。
- 接口：`POST /api/lulc/reference` → `{products: [{id, year, tiles, stats}]}`；
  `POST /api/lulc/compare` → `{matrix, oa, kappa}`。
- 前端：图层栏加「参考产品」下拉（WorldCover 2021 / IO LULC 2024），可并排对比；
  右栏显示混淆矩阵（百分比热力表）。
- 用途：既能当参考底图，也能给方案 C 预填样本。

### C. 样本 + 随机森林（1–2 周，2.x）

- 样本：地图点选/框选 + 导入 GeoJSON（`samples.geojson`，properties.class），
  支持从参考产品自动采样（稳定像元）。
- 特征：6 波段 + NDVI/NDWI/MNDWI/NDBI/BSI/NDMI + 可选多期中值 + 可选 DEM。
- 模型：`sklearn.ensemble.RandomForestClassifier`（`n_estimators=200`，`class_weight="balanced"`），
  留出 30% 做混淆矩阵 / OA / Kappa / 各类 PA·UA。
- 依赖：`scikit-learn` 走可选依赖（`pip install rspipe[ml]`），安装包评估是否内置。
- 精度预期：85–90%（有样本 + 单期），多期 + DEM 更高。

## 7. 风险

- **阈值法上限**：单景 + 无样本，建设用地易高估（已实测 47% vs 实际更低）。
  缓解：M1 就暴露阈值面板让用户调，并提示"仅供参考"。
- **单景时相**：耕地/草地、水田/旱地难分。缓解：M2 用参考产品对比暴露问题，2.x 上多期合成。
- **安装包体积**：sklearn + scipy 约 +30 MB。缓解：可选依赖，或 M1/M2 不引入。
- **数据许可**：WorldCover / IO LULC / CLCD 均 CC-BY，需在界面与导出 README 署名。
- **分幅编号**：WorldCover 按 3° 分幅、IO LULC 按 UTM supercell，AOI 跨幅要拼接（复用现有镶嵌思路）。

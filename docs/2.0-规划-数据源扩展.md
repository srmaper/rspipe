# 2.0 规划：数据源扩展（免费遥感影像）

> 记录于 2026-11-01。状态：**规划中，未开工**。与 `docs/2.0-规划-土地利用分类.md` 配套。
> 范围：除现有 Sentinel-2 L2A / Landsat 8-9 C2 L2 之外，还能免费接哪些影像，以及接进来的代价。

## 1. 结论

- **Planetary Computer 现有 139 个集合**（2026-11-01 实测），其中大量是本项目可直接吃的
  「STAC + 免费 SAS 签名 + COG」。这类**基本只改配置**：`configs/providers.yaml` 加 collection、
  `configs/sensors.yaml` 加波段映射、必要时补一个渲染规则。
- 真正的工作量在**渲染与读取**：SAR（单波段 dB）、DEM（高程色带/晕渲）、
  MODIS（正弦投影）、S3/S5P（NetCDF），都不是现在的「多波段反射率 → 真彩」路径。
- **国产卫星（高分/资源/环境）没有 STAC、要实名申请、只能整景下载**，
  建议走「本地文件导入」而不是在线检索。
- 天地图 / Google / 高德等**只能当底图**，ToS 不允许批量下载与再分发，不进下载链。

### 接入方式（已有通道）

1. `configs/providers.yaml`：`planetary-computer` 的 `collections` 追加即可，鉴权仍是 `auth: none`
   （资产走 SAS 签名）。
2. `configs/sensors.yaml`：加传感器的 `band_map`（通用名 → 产品波段名）与 `qa_band`。
3. `src/rspipe/clients/stac.py`：`item_to_scene` 里按 collection 决定可用波段与资产键。
4. `src/rspipe/web/tiles.py`：新增渲染分支：
   - `render_gray_tile`（dB / 反射率单波段）
   - `render_elevation_tile`（高程色带，可选晕渲）
   - `render_class_tile`（离散色板，最近邻）
5. `src/rspipe/web/preview.py`：本地 raw 预览按同一套渲染分支走。

## 6. 优先级与里程碑

| 版本 | 内容 | 理由 |
|---|---|---|
| 2.1 | **Sentinel-1 GRD**（dB 渲染）+ **Copernicus DEM 30m**（高程/晕渲） | 全天候 + 地形，直接提升现有分析与分类 |
| 2.2 | **HLS L30/S30** + **MODIS NDVI/LST** | 补云洞、上物候时序 |
| 3.0 | NISAR、S3/S5P（NetCDF）、国产本地导入 | 新传感器与新数据形态 |

每档的验收：能检索 → 能预览 → 能按 AOI 下载 → 能进分析（指数/分类）→ 能导出。

## 7. 实现注意

- **投影**：MODIS 是正弦投影，现有 `plan_tile_window` 假定 4326/3857 输入，需先重投影到 3857 瓦片
  或用 GDAL 的 `WarpedVRT`。
- **单波段渲染**：S1 需 dB 拉伸（-25~0 dB），DEM 需色带 + 可选 hillshade，分类值必须最近邻（不能双线性）。
- **NetCDF**：S3/S5P/ERA5 是 2D lat/lon 网格，`rioxarray` 可读但需按经纬度子集切窗；
  不能直接套 COG 的 window 逻辑。
- **体量与缓存**：MODIS 全球日产品数量大，检索与预览必须走现有磁盘缓存
  （`src/rspipe/cache.py`），并给集合级 TTL。
- **命名与去重**：同一景可能同时来自 earth-search / PC / CDSE，沿用现有 `scene_id` 去重。
- **许可与署名**：所有新增源都要求在界面「数据来源」与导出 README 中署名（CC-BY / 公有领域）。
